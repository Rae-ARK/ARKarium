## Despre ce este vorba

ARKarium este construit în jurul distribuției directe de la Rae ARK către cititorul său.

Conținutul este publicat sub formă de fișiere pe un relay și sincronizat cu biblioteca locală a cititorului. Clientul gestionează experiența de citire, fără a necesita un backend de platformă permanent.

## Instalare

ARKarium poate fi urmărit și actualizat prin [Obtainium](https://github.com/ImranR98/Obtainium).

Obtainium permite utilizatorilor să instaleze și să urmărească aplicații Android direct din repozitoriile sursă, fără a depinde de un magazin de aplicații centralizat.

**Pentru a instala:**

1. Instalați [Obtainium](https://github.com/ImranR98/Obtainium).
2. Faceți clic pe insigna **Get it on Obtainium** de mai sus.
3. Confirmați configurația aplicației ARKarium.
4. Obtainium va urmări repozitoriul pentru actualizări disponibile.

Alternativ, descărcați cea mai recentă versiune direct de pe [GitHub Releases](https://github.com/Rae-ARK/ARKarium/releases/).

## Stare

> [!WARNING]
> Dezvoltare timpurie. Etapă beta.
>
> Aplicația din versiunea curentă funcționează bine și poate fi folosită pentru citit.
> V1 nu este încă finalizată. Erorile sunt normale.
>
> Aplicația și romanele sunt deocamdată în engleză. 
> Mai multe limbi? Poate cândva în viitor. 
> Depinde de cererea cititorilor. 
>
> Poate una sau două traduceri ca lumea. Restul s-ar putea să ajungă traduceri automate (MTL).
