## นี่คืออะไร

ARKarium ถูกสร้างขึ้นโดยมีแนวคิดหลักคือการเผยแพร่โดยตรงจาก Rae ARK ไปยังผู้อ่าน

เนื้อหาจะถูกเผยแพร่เป็นไฟล์บนรีเลย์และซิงค์กับคลังหนังสือในเครื่องของผู้อ่าน ไคลเอนต์เป็นผู้จัดการประสบการณ์การอ่านเอง โดยไม่จำเป็นต้องมีแบ็กเอนด์แพลตฟอร์มถาวร

## จุดเด่น

- การอ่านแบบเน้นข้อมูลในเครื่องก่อน
- การเผยแพร่โดยตรงจาก Rae ARK ถึงผู้อ่าน
- การซิงค์เนื้อหาแบบเพิ่มทีละส่วน
- เนื้อหาแบบคงที่และการเผยแพร่ที่เรียบง่าย
- ไคลเอนต์สำหรับ Android

### สิ่งที่จะเกิดขึ้นในอนาคต

- การแปลงข้อความเป็นเสียงพูดที่รู้จักตัวละคร
- การอ่านด้วยหลายเสียง
- ออกแบบมาเพื่อประสบการณ์นิยายที่สมบูรณ์แบบ
- ไคลเอนต์สำหรับเดสก์ท็อป

## การติดตั้ง

สามารถติดตามและอัปเดต ARKarium ได้ผ่าน [Obtainium](https://github.com/ImranR98/Obtainium)

Obtainium ช่วยให้ผู้ใช้สามารถติดตั้งและติดตามแอปพลิเคชัน Android ได้โดยตรงจากที่เก็บซอร์สโค้ด โดยไม่ต้องพึ่งพาร้านค้าแอปแบบรวมศูนย์

**วิธีติดตั้ง:**

1. ติดตั้ง [Obtainium](https://github.com/ImranR98/Obtainium)
2. คลิกที่ตรา **Get it on Obtainium** ด้านบน
3. ยืนยันการตั้งค่าแอปพลิเคชัน ARKarium
4. Obtainium จะติดตามที่เก็บข้อมูลเพื่อหาอัปเดตที่มีอยู่

หรือดาวน์โหลดรุ่นล่าสุดโดยตรงจาก [GitHub Releases](https://github.com/Rae-ARK/ARKarium/releases/)

## สถานะ

อยู่ในช่วงพัฒนาเบื้องต้น ระยะเบต้า

แอปรุ่นปัจจุบันทำงานได้ดีและสามารถใช้อ่านได้ตามปกติ  
เวอร์ชัน V1 ยังไม่เสร็จสมบูรณ์ การพบข้อผิดพลาดถือเป็นเรื่องปกติ
