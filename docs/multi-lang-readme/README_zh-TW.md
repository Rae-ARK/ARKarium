## 簡介

ARKarium 的核心是從 Rae ARK 直接分發給讀者。

內容以檔案形式發布到中繼伺服器，並同步到讀者的本機書庫。用戶端負責處理閱讀體驗，而不需要依賴永久性的平台後端。

## 安裝

ARKarium 可透過 [Obtainium](https://github.com/ImranR98/Obtainium) 進行追蹤和更新。

Obtainium 讓使用者可以直接從原始碼儲存庫安裝並追蹤 Android 應用程式，而不需依賴集中式應用程式商店。

**安裝步驟：**

1. 安裝 [Obtainium](https://github.com/ImranR98/Obtainium)。
2. 點擊上方的 **Get it on Obtainium** 徽章。
3. 確認 ARKarium 應用程式設定。
4. Obtainium 將持續追蹤該儲存庫的可用更新。

或者，直接從 [GitHub Releases](https://github.com/Rae-ARK/ARKarium/releases/) 下載最新版本。

## 狀態

早期開發階段，測試版。

目前發布的應用程式本身運作良好，可正常用於閱讀。  
V1 版本尚未完成，出現問題屬於正常現象。
