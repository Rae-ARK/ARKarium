## ഇതെന്താണ്

Rae ARK-ൽ നിന്ന് വായനക്കാരനിലേക്ക് നേരിട്ടുള്ള വിതരണത്തെ അടിസ്ഥാനമാക്കിയാണ് ARKarium നിർമ്മിച്ചിരിക്കുന്നത്.

ഉള്ളടക്കം ഒരു റിലേയിൽ ഫയലുകളായി പ്രസിദ്ധീകരിക്കുകയും വായനക്കാരന്റെ പ്രാദേശിക ലൈബ്രറിയുമായി സമന്വയിപ്പിക്കുകയും ചെയ്യുന്നു. സ്ഥിരമായ ഒരു പ്ലാറ്റ്‌ഫോം ബാക്കെൻഡ് ആവശ്യമില്ലാതെ, ക്ലയന്റ് തന്നെ വായനാനുഭവം കൈകാര്യം ചെയ്യുന്നു.

- ഇൻക്രിമെന്റൽ ഉള്ളടക്ക സമന്വയം
- സ്റ്റാറ്റിക് ഉള്ളടക്കവും ലളിതമായ വിതരണവും

## ഇൻസ്റ്റലേഷൻ

[Obtainium](https://github.com/ImranR98/Obtainium) വഴി ARKarium ട്രാക്ക് ചെയ്യാനും അപ്ഡേറ്റ് ചെയ്യാനും കഴിയും.

കേന്ദ്രീകൃതമായ ഒരു ആപ്പ് സ്റ്റോറിനെ ആശ്രയിക്കാതെ, സോഴ്സ് റിപ്പോസിറ്ററികളിൽ നിന്ന് നേരിട്ട് ആൻഡ്രോയിഡ് ആപ്ലിക്കേഷനുകൾ ഇൻസ്റ്റാൾ ചെയ്യാനും ട്രാക്ക് ചെയ്യാനും Obtainium ഉപയോക്താക്കളെ അനുവദിക്കുന്നു.

**ഇൻസ്റ്റാൾ ചെയ്യാൻ:**

1. [Obtainium](https://github.com/ImranR98/Obtainium) ഇൻസ്റ്റാൾ ചെയ്യുക.
2. മുകളിലുള്ള **Get it on Obtainium** ബാഡ്ജിൽ ക്ലിക്ക് ചെയ്യുക.
3. ARKarium ആപ്ലിക്കേഷൻ കോൺഫിഗറേഷൻ സ്ഥിരീകരിക്കുക.
4. ലഭ്യമായ അപ്ഡേറ്റുകൾക്കായി Obtainium റിപ്പോസിറ്ററി ട്രാക്ക് ചെയ്യും.

പകരമായി, [GitHub Releases](https://github.com/Rae-ARK/ARKarium/releases/) ൽ നിന്ന് നേരിട്ട് ഏറ്റവും പുതിയ റിലീസ് ഡൗൺലോഡ് ചെയ്യുക.
