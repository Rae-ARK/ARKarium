## Что это такое

ARKarium построен вокруг прямого распространения от Rae ARK к читателю.

Контент публикуется в виде файлов на релее и синхронизируется с локальной библиотекой читателя. Клиент сам отвечает за процесс чтения, не требуя постоянного серверного бэкенда платформы.

## Основные возможности

- Чтение с приоритетом локального хранения
- Прямое распространение от Rae ARK к читателям
- Инкрементальная синхронизация контента
- Статичный контент и простое распространение
- Android-клиент

### В перспективе

- Озвучивание текста с учётом персонажей
- Чтение несколькими голосами
- Разработано для насыщенного опыта чтения художественной литературы
- Клиент для настольных систем

## Установка

ARKarium можно отслеживать и обновлять через [Obtainium](https://github.com/ImranR98/Obtainium).

Obtainium позволяет пользователям устанавливать и отслеживать Android-приложения напрямую из исходных репозиториев, без зависимости от централизованного магазина приложений.

**Чтобы установить:**

1. Установите [Obtainium](https://github.com/ImranR98/Obtainium).
2. Нажмите на значок **Get it on Obtainium** выше.
3. Подтвердите конфигурацию приложения ARKarium.
4. Obtainium будет отслеживать репозиторий на предмет доступных обновлений.

Либо скачайте последний релиз напрямую со страницы [GitHub Releases](https://github.com/Rae-ARK/ARKarium/releases/).
