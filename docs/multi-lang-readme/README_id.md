## Tentang Aplikasi Ini

ARKarium dibangun di sekitar distribusi langsung dari Rae ARK ke pembacanya.

Konten dipublikasikan sebagai berkas pada sebuah relay dan disinkronkan ke pustaka lokal pembaca. Klien yang menangani pengalaman membaca, bukan memerlukan backend platform yang permanen.

## Sorotan

- Membaca yang mengutamakan data lokal
- Distribusi langsung dari Rae ARK ke pembaca
- Sinkronisasi konten secara inkremental
- Konten statis dan distribusi sederhana
- Klien Android

### Rencana ke Depan

- [ ] Text-to-speech yang menyadari karakter
- [ ] Pembacaan dengan banyak suara
- [ ] Dirancang untuk pengalaman fiksi yang kaya
- [ ] Klien desktop

## Instalasi

ARKarium dapat dilacak dan diperbarui melalui [Obtainium](https://github.com/ImranR98/Obtainium).

Obtainium memungkinkan pengguna menginstal dan melacak aplikasi Android langsung dari repositori sumbernya, tanpa bergantung pada toko aplikasi terpusat.

**Cara menginstal:**

1. Instal [Obtainium](https://github.com/ImranR98/Obtainium).
2. Klik lencana **Get it on Obtainium** di atas.
3. Konfirmasi konfigurasi aplikasi ARKarium.
4. Obtainium akan melacak repositori untuk pembaruan yang tersedia.

Sebagai alternatif, unduh rilis terbaru langsung dari [GitHub Releases](https://github.com/Rae-ARK/ARKarium/releases/).
