## O que é

O ARKarium é construído em torno da distribuição direta de Rae ARK para seu leitor.

O conteúdo é publicado como arquivos em um relay e sincronizado com a biblioteca local do leitor. O cliente cuida da experiência de leitura, em vez de exigir um backend de plataforma permanente.

## Destaques

- Leitura local-first
- Distribuição direta de Rae ARK para os leitores
- Sincronização incremental de conteúdo
- Conteúdo estático e distribuição simples
- Cliente Android

### Para o futuro

- Texto para voz com reconhecimento de personagens
- Leitura com múltiplas vozes
- Projetado para uma experiência rica de ficção
- Cliente para desktop

## Instalação

O ARKarium pode ser acompanhado e atualizado por meio do [Obtainium](https://github.com/ImranR98/Obtainium).

O Obtainium permite que os usuários instalem e acompanhem aplicativos Android diretamente de seus repositórios de origem, sem depender de uma loja de aplicativos centralizada.

**Para instalar:**

1. Instale o [Obtainium](https://github.com/ImranR98/Obtainium).
2. Clique no selo **Get it on Obtainium** acima.
3. Confirme a configuração do aplicativo ARKarium.
4. O Obtainium acompanhará o repositório em busca de atualizações disponíveis.

Alternativamente, baixe a versão mais recente diretamente do [GitHub Releases](https://github.com/Rae-ARK/ARKarium/releases/).
