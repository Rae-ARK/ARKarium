## 개요

ARKarium은 Rae ARK가 독자에게 직접 배포하는 방식을 중심으로 만들어졌습니다.

콘텐츠는 릴레이 서버에 파일 형태로 게시되어 독자의 로컬 라이브러리와 동기화됩니다. 영구적인 플랫폼 백엔드가 필요 없이 클라이언트가 읽기 경험을 처리합니다.

## 주요 특징

- 로컬 우선 읽기
- Rae ARK가 독자에게 직접 배포
- 증분 콘텐츠 동기화
- 정적 콘텐츠와 단순한 배포
- 안드로이드 클라이언트

### 향후 계획

- 캐릭터를 인식하는 텍스트 음성 변환
- 다중 음성 낭독
- 풍부한 소설 경험을 위한 설계
- 데스크톱 클라이언트

## 설치

ARKarium은 [Obtainium](https://github.com/ImranR98/Obtainium)을 통해 추적 및 업데이트할 수 있습니다.

Obtainium을 사용하면 중앙 집중식 앱 스토어에 의존하지 않고 소스 저장소에서 직접 Android 애플리케이션을 설치하고 추적할 수 있습니다.

**설치 방법:**

1. [Obtainium](https://github.com/ImranR98/Obtainium)을 설치합니다.
2. 위의 **Get it on Obtainium** 배지를 클릭합니다.
3. ARKarium 애플리케이션 구성을 확인합니다.
4. Obtainium이 저장소의 업데이트를 추적합니다.

또는 [GitHub Releases](https://github.com/Rae-ARK/ARKarium/releases/)에서 최신 릴리스를 직접 다운로드할 수 있습니다.
