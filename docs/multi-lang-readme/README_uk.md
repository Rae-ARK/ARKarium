## Що це таке

ARKarium побудований навколо прямого розповсюдження від Rae ARK до читача.

Контент публікується у вигляді файлів на релеї та синхронізується з локальною бібліотекою читача. Клієнт сам відповідає за процес читання, не потребуючи постійного серверного бекенду платформи.

## Основні можливості

- Читання з пріоритетом локального зберігання
- Пряме розповсюдження від Rae ARK до читачів
- Інкрементальна синхронізація контенту
- Статичний контент і просте розповсюдження
- Клієнт для Android

## Встановлення

ARKarium можна відстежувати й оновлювати через [Obtainium](https://github.com/ImranR98/Obtainium).

Obtainium дозволяє користувачам встановлювати та відстежувати Android-додатки безпосередньо з вихідних репозиторіїв, без залежності від централізованого магазину додатків.

**Щоб встановити:**

1. Встановіть [Obtainium](https://github.com/ImranR98/Obtainium).
2. Натисніть на значок **Get it on Obtainium** вище.
3. Підтвердіть конфігурацію застосунку ARKarium.
4. Obtainium відстежуватиме репозиторій на наявність оновлень.

Або завантажте останню версію безпосередньо зі сторінки [GitHub Releases](https://github.com/Rae-ARK/ARKarium/releases/).
