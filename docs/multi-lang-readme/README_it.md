## Di cosa si tratta

ARKarium è costruito attorno alla distribuzione diretta da Rae ARK al lettore.

I contenuti vengono pubblicati come file su un relay e sincronizzati con la libreria locale del lettore. Il client gestisce l'esperienza di lettura, senza richiedere un backend di piattaforma permanente.

## Punti salienti

- Lettura local-first
- Distribuzione diretta da Rae ARK ai lettori
- Sincronizzazione incrementale dei contenuti
- Contenuti statici e distribuzione semplice
- Client Android

### In prospettiva futura

- [ ] Sintesi vocale consapevole dei personaggi
- [ ] Lettura multi-voce
- [ ] Progettato per un'esperienza narrativa ricca
- [ ] Client desktop

## Installazione

ARKarium può essere monitorato e aggiornato tramite [Obtainium](https://github.com/ImranR98/Obtainium).

Obtainium consente agli utenti di installare e monitorare applicazioni Android direttamente dai relativi repository sorgente, senza dipendere da uno store centralizzato.

**Per installare:**

1. Installa [Obtainium](https://github.com/ImranR98/Obtainium).
2. Clicca sul badge **Get it on Obtainium** qui sopra.
3. Conferma la configurazione dell'applicazione ARKarium.
4. Obtainium monitorerà il repository per gli aggiornamenti disponibili.

In alternativa, scarica l'ultima versione direttamente da [GitHub Releases](https://github.com/Rae-ARK/ARKarium/releases/).
