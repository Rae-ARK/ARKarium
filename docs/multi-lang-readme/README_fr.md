## Ce que c'est

ARKarium est conçu autour d'une distribution directe de Rae ARK vers son lecteur.

Le contenu est publié sous forme de fichiers sur un relais et synchronisé avec la bibliothèque locale du lecteur. Le client gère l'expérience de lecture, sans nécessiter de backend de plateforme permanent.

## Points forts

- Lecture axée sur le local
- Distribution directe de Rae ARK aux lecteurs
- Synchronisation incrémentale du contenu
- Contenu statique et distribution simple
- Client Android

### À plus long terme

- Synthèse vocale sensible aux personnages
- Lecture multi-voix
- Conçu pour une expérience de fiction riche
- Client de bureau

## Installation

ARKarium peut être suivi et mis à jour via [Obtainium](https://github.com/ImranR98/Obtainium).

Obtainium permet aux utilisateurs d'installer et de suivre des applications Android directement depuis leurs dépôts source, sans dépendre d'un magasin d'applications centralisé.

**Pour installer :**

1. Installez [Obtainium](https://github.com/ImranR98/Obtainium).
2. Cliquez sur le badge **Get it on Obtainium** ci-dessus.
3. Confirmez la configuration de l'application ARKarium.
4. Obtainium suivra le dépôt pour détecter les mises à jour disponibles.

Vous pouvez également télécharger la dernière version directement depuis [GitHub Releases](https://github.com/Rae-ARK/ARKarium/releases/).
